## Featured projects

### [PyREA](https://github.com/mustaph333/pyrea)
An evidence-first code analyzer in pure Python (no dependencies).
Point it at a Python, JavaScript or binary file and it explains what the
code does — every finding labelled *observation*, *derivation*,
*inference* or *unknown*, with the evidence attached.

```bash
python -m pyrea analyze your_file.py
```

### [ClipForge](https://github.com/mustaph333/clipforge)
A free, local AI video studio. Topic in — finished vertical video out:
script, voiceover, slides and burned-in subtitles, on your own machine.
No subscriptions, no per-video fees, no accounts.

```bash
python -m clipforge "the old medina of Tangier"
```
